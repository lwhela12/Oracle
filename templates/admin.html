Metric definitions & limitations
  • Completed readings count distinct request IDs with a completed server generation. Retries with the same request ID count once. This does not prove the result appeared on screen or was read.
  • Completion rate uses requests started in the selected period at least 15 minutes before its end. Recent starts are excluded to allow time to finish.
  • Active browsers are anonymous browser identifiers with a completed reading. Devices, cleared storage, bots, and privacy opt-outs affect these counts; they are not a count of people.
  • Median and 95th-percentile duration use completed attempts with reported timing. Daily totals use America/Los_Angeles calendar days, including the incomplete current day.
  • Only public traffic from the configured environment is included. Test and internal traffic are excluded. Events are retained for 90 days; collection is best effort and may have gaps.
  • Token counts include only reported values. Missing usage is unknown, not zero cost. Retention cohorts and revenue metrics are not available in this release.
